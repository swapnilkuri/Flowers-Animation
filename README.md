# 🌸 Blooming Butterfly Ginger Lilies

> *"POV: She wanted flowers, so I coded them."*

An interactive, pure HTML5 Canvas and JavaScript animation featuring procedural, blooming **White Butterfly Ginger Lilies** (*Hedychium coronarium*). Stems rise organically from the bottom of the screen, unfurling delicate white petals, soft golden centers, and broad tropical leaves against a moody botanical backdrop.

---

## ✨ Features

* **Custom Floral Anatomy:** Modeled specifically after Butterfly Ginger Lilies with distinctive wing-like petals, broad foliage, and arching stamens.
* **Procedural Growth & Bloom:** Each flower grows at a unique speed, height, and gentle sway before naturally blooming.
* **Pure Vanilla Web Stack:** Zero dependencies — built purely with HTML5, CSS3, and native Canvas API.
* **Ambient Visuals:** Includes floating light particles and a soft fading message overlay.
* **Fully Responsive:** Adapts smoothly to various screen sizes and resolutions.
